3. 핵심 기능 검증 항목
--------------------------------------------------------------------------------
[V] 1. 창모드 렌더링 래퍼 배치 (cnc-ddraw v7.1.0.0)
    - ddraw.dll 및 Shaders가 게임 디렉토리(z:\my\창세기전\창세기전3 파트2\)에 정상 배치됨.
    - ddraw.ini 최적 설정:
      * windowed = true
      * fullscreen = false
      * border = false (런처 임베딩을 위한 테두리 제거)
      * maintas = true (4:3 고유 종횡비 유지)
      * renderer = auto (D3D9/OpenGL/GDI 호환)
      * devmode = true (커서 자유 모드 지원)
      * nonexclusive = true (HWND SetParent 도킹 호환성)

[V] 2. 런처 내부 게임 창 도킹 (GameEmbedder)
    - 프로세스 시작 후 EnumWindows + PID 매칭을 통해 게임 메인 HWND 자동 탐색.
    - SetWindowLongPtr 호출로 WS_CHILD, WS_VISIBLE, WS_CLIPSIBLINGS 스타일 적용.
    - SetParent(gameHwnd, viewportPanelHwnd)로 런처 창 내부 뷰포트 패널로 게임 창을 도킹.
    - 런처 창 이동 및 최소화 시 게임 창이 함께 연동.

[V] 3. 화면 배율 스케일러 (아이디어 1)
    - 1.0x (800 x 600)
    - 1.25x (1000 x 750)
    - 1.5x (1200 x 900)
    - 런처 버튼 클릭 시 런처 창과 내부 뷰포트가 실시간 정수/비례 확대되며 SetWindowPos 반영.

[V] 4. 마우스 커서 자유 탈출 토글 (아이디어 3)
    - F11 단축키 및 런처 우측 버튼을 통해 ClipCursor(IntPtr.Zero) 마우스 자유 탈출 지원.
    - 게임 도중 런처 창 밖으로 마우스를 빼서 웹 서핑, 공략 확인, 멀티태스킹 가능.

[V] 5. 사운드 볼륨 제어 슬라이더 (아이디어 4)
    - BGM 볼륨 (0~100) 및 SFX 볼륨 (0~100) 실시간 레지스트리(TheWarofGenesis3PartII) 반영.
